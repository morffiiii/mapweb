# Terra — карта личных открытий

Приложение для личных прогулок: реальная карта, туман с радиусом открытия 35 м, пять режимов движения, отдельные слои, пауза, история, статистика, экспорт и импорт JSON. Демо не сохраняется в личный прогресс. Регистрация и сервер маршрутов не нужны.

Интерфейс использует графитовую и светлую темы с оранжевым акцентом. Переключатель солнце/луна находится в шапке; выбор сохраняется на устройстве. Вместе с панелями меняются карта и туман, записанные маршруты сохраняются при переключении.

## Запуск на Windows

Нужен Node.js 22+ и pnpm 11.19.0 (можно установить через `npm install -g pnpm@11.19.0`).

```sh
pnpm install
pnpm dev
```

Открой адрес из терминала. Для геолокации подходят localhost или HTTPS. Обычный HTTP по локальному IP на телефоне не подходит. `pnpm build` создаёт веб-версию в `dist`; `pnpm test` проверяет расчёт расстояний, фильтрацию координат, паузы, объединение открытой территории и резервные копии.

## Бесплатная установка на iPhone без своего Mac

1. Создай репозиторий на GitHub и загрузи проект. Для публичного репозитория стандартные GitHub Actions бесплатны; для закрытого следи за бесплатной квотой. Не загружай резервные копии маршрутов, пароли или ключи.
2. В Actions запусти `Build iPhone IPA`. Облачный Mac соберёт проект через Xcode. Первый запуск нужно проверить: локально на Windows компиляция Swift/iOS недоступна.
3. Скачай артефакт `Terra-iPhone` и распакуй `Terra-unsigned.ipa`.
4. Установи Sideloadly с https://sideloadly.io/ и необходимые компоненты Apple для Windows по его инструкции. Подключи iPhone кабелем, подтверди доверие компьютеру.
5. Выбери IPA и свой Apple Account в Sideloadly. Пароль вводится только в установленном инструменте, не в проекте или GitHub Actions. Sideloadly подписывает готовый файл бесплатной подписью.
6. При запросе iOS доверься разработчику в «Настройки → Основные → VPN и управление устройством». Если iOS требует режим разработчика, включи его в «Конфиденциальность и безопасность → Режим разработчика» и перезагрузи телефон.
7. В Terra нажми «Начать прогулку», разреши точную геопозицию при использовании приложения. Уже начатая запись использует фоновый режим location и системный индикатор.
8. Обновляй подпись до истечения 7 дней через Sideloadly. Его автоматическое обновление требует доступного Windows-компьютера и соединения с телефоном. Экспортируй резервную копию перед удалением/переустановкой приложения.

## Что важно проверить на настоящем iPhone

- Начни прогулку на улице и дождись точек GPS. Пройди 2 минуты с открытым экраном, 5 минут с заблокированным и 5 минут с другим приложением. Вернись и проверь непрерывность точек и маршрута.
- Поставь паузу, пройди участок, продолжи. Между участками не должно быть соединяющей линии.
- Заверши и перезапусти приложение: история и туман должны сохраниться.
- Повтори с отключённым интернетом: координаты должны сохраниться нативно, но незагруженная карта без сети недоступна.
- Экспортируй файл через системное меню «Поделиться», импортируй его обратно. Дубликатов маршрутов быть не должно.
- Отключи разрешение геолокации во время записи: приложение должно поставить запись на паузу.

## Архитектура и ограничения

- Веб-интерфейс: Vite, MapLibre GL JS, OpenFreeMap, OpenStreetMap. Интернет нужен для карты и шрифта; системный шрифт работает без сети. Атрибуция карты остаётся видимой.
- Веб-запись: `watchPosition`, локальное хранилище, только при активной странице. После перезагрузки незавершённый маршрут открывается на паузе. Удаление данных сайта удаляет маршруты.
- iOS: собственный Capacitor-плагин `native/ios/TerraTracker.swift`. Core Location работает независимо от JS, каждый пакет точек сохраняется атомарно в Application Support. Защита файла позволяет писать при заблокированном экране после первой разблокировки. Нативный снимок синхронизируется при возврате в интерфейс.
- Принудительное закрытие приложения, выключение телефона и отключение разрешений прерывают запись. После перезапуска маршрут на паузе; автоматическая запись всего дня не реализована.
- Радиус 35 м. Открытая площадь — приближённое объединение ячеек 20 × 20 м. Координаты с погрешностью более 60 м, скачки скорости и дрожание менее 4 м отбрасываются. Пропуски более 60 секунд не соединяются. Полярные области выше 85° не поддерживаются.
- Android: веб-интерфейс доступен; нативная фоновая запись Android ещё не реализована. Основная платформа этой версии — iPhone.
- Данные геопозиции не отправляются на наш сервер. Картографический сервис получает запросы тайлов для просматриваемых областей. Платный сервер и ключ карты не нужны для текущего прототипа.
- Для больших многолетних архивов файловое хранение и отрисовку всех точек следует заменить SQLite и пространственным индексом. Сейчас это личная первая версия, без аккаунтов, фото, достижений и социального слоя.

## Файлы

- `src/main.js`, `src/style.css`: интерфейс, карта, туман, демо.
- `src/geo.js`: расстояния, фильтры, приблизительная площадь, проверка импорта.
- `src/storage.js`: веб-запись и мост к iOS.
- `native/ios/TerraTracker.swift`: фоновая запись и хранение iOS.
- `scripts/prepare-ios.mjs`: подключение нативного кода и разрешений к сгенерированному iOS-проекту.
- `.github/workflows/ios.yml`: сборка unsigned IPA на облачном Mac.

Проверенные справочные источники: https://capacitorjs.com/docs/ios/custom-code , https://developer.apple.com/documentation/corelocation/handling-location-updates-in-the-background , https://docs.github.com/en/billing/concepts/product-billing/github-actions , https://sideloadly.io/ .
