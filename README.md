# Terra — нативная карта личных открытий

Версия 2.2 использует мобильное приложение Swift/UIKit/MapKit для iOS и Kotlin/MapLibre Native для Android. HTML, JavaScript, Capacitor и WebView в новые мобильные сборки не включаются. Старый веб-прототип оставлен в `src/` отдельно для истории разработки.

## Возможности

- Нативные жесты карты: перемещение и масштабирование.
- Текущая геопозиция после выдачи разрешения, до начала записи; кнопка «Где я».
- Немедленный старт после разрешения геолокации; координаты добавляются после получения точного GPS. Пауза, продолжение, завершение.
- Пешком, автомобиль, велосипед, другое; фильтрация открытий по способу. Старые мотомаршруты относятся к «Другое».
- Серый туман с открытием полосы радиусом 17,5 м вдоль записанного пути.
- История маршрутов, расстояние и время; оценка общей открытой площади без повторного подсчёта пересечений.
- Светлая, тёмная и системная тема; оранжевый акцент.
- Локальное атомарное сохранение. Кнопки экспорта/импорта убраны по запросу; прежний формат маршрутов сохранён для обновления на месте.
- Фоновая запись: Core Location на iOS, foreground location service с уведомлением на Android.
- Нет демонстрационных маршрутов или сервера хранения геопозиции. Есть локальный профиль с обязательной регистрацией или входом.

## Новое в 2.1

- Собственные экраны профиля, истории, настроек и слоёв; нижняя навигация только с иконками и доступными подписями для VoiceOver/TalkBack.
- Следование за точкой при записи; ручное перемещение карты приостанавливает следование, кнопка местоположения возвращает его.
- Воспроизведение открытия маршрута после завершения и из истории.
- Личные места с заметками и фото: удержание точки на карте, просмотр из профиля.
- Подробная статистика вынесена в отдельный раздел; выбор квартала убран из профиля.
- Поиск неоткрытых участков рядом по сетке прогресса. Это кандидаты по прямой, без проверки проходимости или маршрутизации по улицам.
- Личные цели по километрам, количеству маршрутов и площади, с названием и прогрессом. Учитываются все завершённые маршруты.
- Достижения за фактический прогресс.
- Серия прогулок: день засчитывается по местной дате завершения пешего маршрута длительностью от 5 минут с движением. Вчерашний одиночный пропуск можно восстановить, если позавчера серия шла. До 3 восстановлений за календарный месяц; повторное восстановление одного дня не допускается. День сегодня можно выполнить до полуночи. История восстановлений хранится локально; серверной защиты от изменения часов нет.
- Совместный прогресс отложен по решению пользователя. Яндекс Карты ещё не подключены: требуется собственный API-ключ, см. [инструкцию](docs/YANDEX.md).

## Локальный профиль и знакомство

При первом входе доступны регистрация или вход на этом устройстве; гостевого доступа нет. Почта — локальный логин, она не проверяется сервером. Соль и PBKDF2-HMAC-SHA256 (210 000 итераций) используются для проверки пароля; пароль открытым текстом не сохраняется. Запись учётных данных хранится в Keychain на iOS и в зашифрованном файле AES-GCM с ключом Android Keystore на Android. Это локальная авторизация, не облачный аккаунт и не шифрование всех маршрутов. Восстановления пароля по почте пока нет. Данные на другой телефон не переносятся.

После входа/регистрации — приветствие. Шаги знакомства: необязательные имя, возраст числом, рост и вес, выбор интересов на плашках, источник знакомства с Terra. Каждый шаг можно пропустить. Профиль позволяет менять имя, возраст, рост, вес, интересы и фото; источник знакомства сохраняется только при регистрации; до выбора фото отображается заглушка. Выход не удаляет маршруты, но недоступен во время незавершённой записи.

Серия называется «Ритм»: собственный знак пути со стрелкой, число дней и лента последних семи дней. Восстановленные дни отмечаются отдельно.

## Сборки и установка

Открой [GitHub Actions](https://github.com/morffiiii/mapweb/actions/workflows/ios.yml), выбери последний **успешный** запуск `Native iOS and Android`, скачай артефакт своей платформы. Наличие исходников само по себе не означает успешную сборку. Проверяй статус последнего запуска и отчёты тестов.

### iPhone — iOS 16+

1. Артефакт `Terra-iPhone-native` содержит `Terra-native-unsigned.ipa`.
2. Распакуй ZIP, передай IPA на iPhone и установи через уже настроенный AltStore Classic: My Apps → «+» → IPA.
3. Используй тот же Apple Account и прежний идентификатор приложения. **Не удаляй установленную Terra перед обновлением.** Новая версия использует прежний bundle ID `app.terra.explore` и прежний файл Application Support/terra-state.json; сохранения читаются при обновлении на месте. Если установщик изменил идентификатор, это будет отдельная установка: не удаляй старую установку и сначала проверь её данные.
4. Разреши точную геопозицию при использовании. Нажми «Начать прогулку», дождись статуса записи, затем блокируй экран.
5. Бесплатную подпись AltStore необходимо регулярно обновлять. Настрой обновление через AltServer, как для уже установленной версии.

IPA не подписан для App Store. Подписание происходит твоим аккаунтом при установке; сертификаты и пароли в репозитории не хранятся.

### Android — Android 8+

Артефакт `Terra-Android-native` содержит устанавливаемый `app-debug.apk`. Это персональная сборка с подписью разработки, **не релиз для Google Play**. Разреши установку из используемого файлового менеджера, установи APK, разреши точную геопозицию и уведомления. Если производитель телефона ограничивает фоновые приложения, разреши Terra работать без ограничения батареи.

Ключ разработки сохраняется в GitHub Actions cache. При удалении/истечении этого cache ключ может измениться: не удаляй приложение без отдельной копии данных; удаление стирает локальные маршруты и места. Для публичного распространения требуется постоянный закрытый ключ подписи в защищённых секретах CI, release-сборка и проверка требований магазина.

## Что проверяет CI

- iOS: unit-тесты фильтра GPS, скоростных скачков, пауз/пропусков, JSON и пересечений открытой площади; UI-тест нативной карты с жестами, стартом, паузой, завершением и сохранением истории после перезапуска. Геопозиция задаётся симулятором, в самом приложении тестовых маршрутов нет.
- Android: unit-тесты фильтра GPS, пауз/пропусков, JSON и пересечений; компиляция устанавливаемого APK.
- Артефакты отчётов: `iOS-test-results`, `Android-test-results`.

Тесты на симуляторе и успешная компиляция не проверяют GPS и энергосбережение реального телефона. Перед использованием для длинных маршрутов проверь 2 минуты с открытым экраном, 5 минут с заблокированным, 5 минут в другом приложении; затем паузу, продолжение, завершение и перезапуск. Android UI и фоновый сервис пока требуют проверки на устройстве.

## Хранение и ограничения

Координаты с погрешностью больше 60 м, дрожание меньше 4 м и неправдоподобная скорость отбрасываются. Паузы и пропуски GPS больше 60 секунд не соединяются прямой линией. При перезапуске прерванная запись открывается на паузе. Принудительная остановка приложения, отзыв разрешений и выключение телефона останавливают запись.

Радиус открытия — 17,5 м (полоса шириной 35 м). Площадь приблизительная, по сетке 20 × 20 м. Поддерживаются широты до ±85°. Для многолетних архивов потребуется пространственный индекс и база данных вместо отрисовки всего архива.

Интернет нужен для незагруженной карты, но GPS-запись от него не зависит. iOS использует Apple Maps. Android использует тайлы OpenStreetMap с идентификатором приложения, кэшированием MapLibre и видимой атрибуцией; массового скачивания карт нет. Картографический провайдер получает запросы просматриваемых областей, наши серверы геопозицию не получают. Условия тайлов: https://operations.osmfoundation.org/policies/tiles/.

## Локальная разработка

### iOS (Mac/Xcode)

```sh
brew install xcodegen
cd mobile/ios
xcodegen generate
open Terra.xcodeproj
```

Схема Terra включает unit/UI tests. Для UI-теста установи геопозицию симулятора. Для Windows сборка выполняется macOS runner в GitHub Actions; локальный Mac не нужен.

### Android (JDK 17, Android SDK 35, Gradle 8.9)

```sh
cd mobile/android
gradle testDebugUnitTest assembleDebug
```

Исходники находятся в `mobile/ios/Terra` и `mobile/android/app/src/main`. Генерируемые Xcode-проекты, APK, IPA и временные файлы сборки исключены из Git.

## Изменения 2.2

На основной карте нет линии маршрута. В истории открывается отдельная карта с толстой линией и воспроизведением, которое не меняет основную карту. В слоях доступны фильтры видимости тумана и личных мест. Слои и настройки — сверху слева; история, геопозиция и профиль — снизу.

Профиль разделён на краткую сводку с «Ритмом» и отдельные разделы статистики, мест, целей, достижений и личных данных. Интересы переключаются без перезагрузки страницы. Место можно открыть нажатием на карту, изменить или удалить.

Скорость рассчитывается по последнему связанному GPS-интервалу и обнуляется на паузе или через 15 секунд без новой точки. Активные калории — приблизительная оценка выше покоя для ходьбы и велосипеда: (MET − 1) × вес × часы записанного движения. Используется указанный вес, иначе 70 кг; рост и возраст не участвуют. Паузы, разрывы GPS и авто не добавляют активных калорий. Категории MET основаны на [2024 Adult Compendium](https://pacompendium.com/adult-compendium/), диапазоны скорости приближённо сопоставлены с [ходьбой](https://pacompendium.com/walking/) и [велосипедом](https://pacompendium.com/bicycling/). Это не измерение с датчиком пульса. При изменении веса исторические оценки пересчитываются.
