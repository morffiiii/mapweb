# Яндекс Карты: подключение следующей сборки

Пока используется Apple Maps на iOS и OpenStreetMap/MapLibre на Android. Подмена тайлов не выполняется: для Яндекса нужен официальный нативный MapKit SDK. Общие маршруты и GPS-хранилище от провайдера карты не зависят.

1. Открой [Кабинет разработчика Яндекса](https://developer.tech.yandex.ru/).
2. Выбери «Подключить API» → **MapKit — мобильный SDK**. Ключ JavaScript API для сайта не подходит.
3. Укажи свой проект Terra и выбери подходящий тариф. Ознакомься с условиями выбранного тарифа в кабинете.
4. Идентификатор приложения обеих платформ: `app.terra.explore`. Ограничения ключа настрой по инструкции кабинета.
5. Сохрани ключ в настройках GitHub-репозитория → Secrets and variables → Actions → New repository secret, имя `YANDEX_MAPKIT_API_KEY`. Не добавляй ключ в публичный исходный код.

После получения ключа нужно подключить SDK к обеим сборкам и заменить карту вместе с проекцией тумана, цветными линиями, метками и движением камеры. **Текущий workflow этот секрет ещё не читает, SDK Яндекса в текущие приложения не входит.** Наличие секрета само по себе карту не переключает. Такая замена требует отдельной проверки сборки и отображения карты с активированным ключом.

Официальные инструкции: [iOS](https://yandex.ru/maps-api/docs/mapkit/ios/generated/getting_started.html), [Android](https://yandex.ru/maps-api/docs/mapkit/android/generated/getting_started.html).

## Где взять ключ

1. Открой https://developer.tech.yandex.ru и войди в Яндекс.
2. «Подключить API» → «MapKit — мобильный SDK».
3. Заполни сведения о Terra и выбери подходящий тариф.
4. Ключ появится в «Интерфейсы API» → «MapKit — мобильный SDK». Активация может занять около 15 минут.
5. Не добавляй ключ в публичный репозиторий; для сборки можно использовать GitHub Actions secret `YANDEX_MAPKIT_API_KEY`. Само добавление секрета карту не переключает: интеграция SDK и чтение ключа из CI ещё нужны.

Официальная инструкция: https://yandex.ru/maps-api/docs/mapkit/ios/generated/getting_started.html

Для Google нужны проект Google Cloud, включённые Maps SDK for iOS / Maps SDK for Android, биллинг и отдельные ограниченные ключи. iOS ограничивается Bundle ID, Android — package и SHA-1 подписи. Основной идентификатор Terra: `app.terra.explore`; после AltStore может отличаться — следует использовать идентификатор подписанной установленной сборки.
